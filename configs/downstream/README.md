# Downstream configurations

This directory contains the public configurations for EC, ESP, active-site,
optimum-pH, and melting-temperature evaluation. The three principal backbone
families use consistent filenames: `esm2_650M.yaml`, `esm2_3B.yaml`, and
`protbert.yaml`.

The public configurations use repository-relative paths and do not contain
server-specific directories or internal result files.

Task-specific paper ablations are placed below the corresponding `ablations/`
directory. Analysis configurations are kept separately under
`configs/analysis/`.
